# Results index

Every number in the README, the report (`reports/analysis.md`, `reports/appendix.md`) and the
figure titles comes from a file listed here; the numbers in figure titles are also saved in the
`figure_stats_*.json` files. Each row names the script that writes the file and, in parentheses,
the make target that runs it: regenerate a file with that target.
Rows marked "not regenerated" are kept as evidence for a decision and are not rewritten by any
target. "Quoted in" names the documents that cite the file and the figures (in `reports/figures/`)
drawn from it.
